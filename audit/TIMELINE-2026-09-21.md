# Goal timeline (v0.38.85, 2026-09-21)

## What

`/goal timeline [N]` (default 20, max 100) renders the live goal's
own trail plus the single next action. Two sources merge by
timestamp: goal-scoped ledger events and `auditHistory` verdicts
(which were never ledgered — the timeline reads them from state).

## Scoping

Entries carrying `goalId` match by id. Older writers omit it, so six
salient unscoped types (pauses, resumes, tweaks, objections TODOs,
decision auto-defaults, provider-retry verdicts) are claimed when
they fall inside the goal's lifetime (`at >= createdAt`). Noise
(`state` snapshots etc., shared with `/glla log`) is excluded;
unknown types render compact `type k=v`, never hidden.

## Next-action derivation (first match wins)

Decision pause → answer it; timed pause → resume time or resume now;
other pause → resume with reason; auditing → wait; submitted claim →
starting; live (non-superseded) disapprovals → address N
objections; complete/aborted → nothing; else working.
